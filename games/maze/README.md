# Лабиринт

`make maze`. Карта — `assets/levels/level01.txt`, читается один раз при запуске; ошибка разбора останавливает игру с номером строки. Строки одной длины, первая — север.

| Символ | Что это |
|---|---|
| `#` | стена |
| `.` | пол |
| `P` | игрок, ровно один; смотрит на первую соседнюю клетку пола в порядке N, E, S, W |
| `E` | орк-патруль; касание начинает уровень заново |
| `o` | монета |
| `k` | ключ |
| `D` | ворота; касание с ключом открывает их и тратит ключ |
| `X` | выход |
| `T` | факел: свет и баннер на первой соседней стене в порядке N, E, S, W; без соседней стены — ошибка, больше 16 — ошибка |
