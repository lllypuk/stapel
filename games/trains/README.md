# Поезда

`make trains`. Песочница в изометрии: состав собирается в депо и ездит по пути со стрелками. Задач, очков и сохранений нет. Камера едет за серединой состава, угол и масштаб не меняются.

| Действие | Ввод |
|---|---|
| Газ вперёд / назад | W/S или ↑/↓; против хода — тормоз до остановки, затем ход в другую сторону |
| Стрелка впереди | E: ближайшая по ходу не дальше 24 м, у стоящего — по последнему направлению хода |
| Стрелка под курсором | ЛКМ в радиусе 2 м от стыка стрелки |
| Депо | Tab |

Активная ветка стрелки светлая, неактивная притемнена. Стрелка под составом не переводится: HUD на секунду пишет `SWITCH BUSY`. Состав встаёт с запасом 0,5 м перед тупиком и перед пошёрстной стрелкой, переведённой на другую ветку: взреза нет.

## Депо

Окно справа сверху открыто на старте, газ при нём выключен. В окне — выбор локомотива, вагоны состава (кнопка `- имя` убирает) и каталог (`+ имя` добавляет, до 5 вагонов). Правка состава ставит его заново в начало депо: хвост у тупика, голова к стрелке. «Ехать» или Tab закрывают окно. Открывает его Tab, только когда состав стоит целиком на пути депо.

## Карта

`assets/maps/level01.toml` вшита в бинарник: правка видна после пересборки. Ошибка разбора при запуске — паника с номером записи (`rail[N]`, `road[N]`, `building[N]`, индекс с 0). Неизвестное поле — тоже ошибка.

```toml
depot = { rail = 5 }    # тупиковая деталь пути депо, индекс в rail

rail = [
    { piece = "straight", cell = [2, 0], rot = 90 },
    { piece = "curve", cell = [4, 0], rot = 90, mirror = true },
]
road = [{ tile = "road-straight", cell = [3, 3], rot = 90 }]
building = [{ model = "building-a", pos = [5.0, 4.5], rot = 180.0, scale = 1.0 }]
```

- `rail` — деталь пути, начало — в узле `cell` сетки 2 м, при `rot = 0` идёт по +Z. `rot` — градусы, кратно 90, любого знака: поворот вокруг начала, +Z → +X. `mirror` отражает деталь по x.

  | `piece` | Конец при `rot = 0` | Выход |
  |---|---|---|
  | `straight` | (0, 4) | +Z |
  | `corner-large` | (−4, 4) | −X |
  | `corner-small` | (−2, 2) | −X |
  | `curve` | (−2, 4), S-сдвиг | +Z |

  `corner-small` разбирается, но для зазора между вагонами тесна: кузова на ней пересекаются, в карте её нет.
- Стык — концы деталей в одной точке с коллинеарными касательными; под углом — ошибка. Стрелка — стык с одной деталью с одной стороны и двумя с другой; по умолчанию активна ветка, записанная раньше. Больше двух деталей с одной стороны или больше одной с обеих — ошибка.
- Путь депо — цепочка деталей от тупика `depot.rail` до первой стрелки; он должен вмещать самый длинный состав с запасом, иначе ошибка.
- `road` — плитка `road-straight`, `road-corner`, `road-crossing`, `road-end`, `grass`, `pond`, `pool` или `plaza`. Клетка `[x, z]` — квадрат (2x, 2z)…(2x + 2, 2z + 2), `rot` кратно 90 — вокруг его центра. Выезды при `rot = 0`: прямая — ±X, поворот — +X и −Z, тупик — +X, перекрёсток — все четыре.
- `building` — `building-a`…`building-f`, `building-skyscraper-a`, `building-skyscraper-b`. `pos` — центр основания (x, z) в метрах, `rot` — градусы, `scale` (по умолчанию 1) умножает общий масштаб зданий.

В `level01` петля 40×16 м: стрелки A и B — обгонный путь вдоль низа петли, C — отросток с обгонного к тупику, D — путь депо сверху. Квартал дорог и зданий — внутри петли.
