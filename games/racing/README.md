# Гонки

`make racing`, другая трасса — `make racing TRACK=track02`. Старт — в гараже с машиной трассы. Заезд на время: круг засчитывается по чекпоинтам на выходе каждой детали в порядке цепочки, время идёт с первого пересечения старта.

| Действие | Клавиши |
|---|---|
| Газ, тормоз | W/S или ↑/↓; заднего хода нет |
| Руль | A/D или ←/→ |
| Ручник | Space |
| За последний чекпоинт | R |
| Заезд машиной, выбранной в гараже | Enter или «Ехать» |
| В гараж, заезд — заново | G |

Сама машина возвращается на середину клетки за последним чекпоинтом, если упала ниже −10 м, 2 с лежит колёсами вверх или 3 с едет вне клеток дороги своего уровня.

## Трасса

`assets/tracks/<имя>.toml`. Файл перечитывается на лету, правка рестартит заезд с прежней машиной: `car` только предвыбирает машину в гараже при запуске. Ошибка разбора оставляет прежнюю трассу и показывает текст со строкой детали в окне; битая трасса при запуске — игра не стартует, ошибка назовёт файл.

```toml
car = "race"            # машина из cars/, предвыбранная в гараже

[[road]]
piece = "roadCornerLarge"
cell = [3, 5]           # якорная клетка по X и Z, клетка — 4 м; до ±1000
level = 0               # уровень высоты, 2 м; по умолчанию 0, до 16
rot = 90                # градусы, кратно 90: поворот вокруг якорной клетки, +Z → +X; по умолчанию 0

[[decor]]
piece = "barrierRed"
pos = [17.0, 0.0, 30.0] # метры
yaw = 30.0              # градусы; по умолчанию 0
```

Дорога — одна замкнутая цепочка от единственного `roadStart`: за выходом каждой детали — вход следующей на том же уровне. Дыра, ветка, занятая клетка или несовпадение уровня — ошибка.

| Деталь | Клетки | Уровни над `level` |
|---|---|---|
| `roadStraight` | 1×1 | 0 |
| `roadStraightLong`, `roadStart` | 1×2 | 0 |
| `roadCornerSmall`, `roadCornerLarge`, `roadCornerLarger` | 1×1, 2×2, 3×3 | 0 |
| `roadRampLong` | 1×2 | подъём с 0 на 1 |
| `roadStraightBridgeStart`, `roadStraightBridge` | 1×1 | 0 и 1, опоры до земли |
| `roadStraightBridgeMid` | 1×1 | только 1: под ним проходит дорога того же `level` |
| `roadRamp` | 1×1 | 0, трамплин: кромка выхода на 1 м выше, приземление на `level` детали |

Барьеры по бокам моста и `roadRampLong` игра ставит сама. Декор: `barrierWall`, `barrierRed`, `barrierWhite` — твёрдые; `rail`, `treeLarge`, `treeSmall`, `grandStand`, `cone` — только рисуются.

## Машина

`assets/cars/<модель>.toml`, модель — `assets/<модель>.glb` из Car Kit, одна из `pieces::CARS`: `race`, `race-future`, `sedan-sports`, `hatchback-sports`. Точки крепления и радиус колёс берутся из габаритов узлов `wheel-*` модели. Читается при запуске.

| Поле | Что это |
|---|---|
| `model` | имя модели без `.glb` |
| `mass` | кг |
| `power` | мощность мотора, Вт |
| `max_speed` | м/с |
| `brake` | тормозная сила на машину, Н |
| `grip_front`, `grip_rear` | множитель трения шин оси |
| `steer_max` | угол руля на месте, градусы |
| `steer_at_speed` | доля `steer_max` на `max_speed`, (0, 1] |
| `spring` | жёсткость пружины колеса, Н/м |
| `damper` | демпфер колеса, Н·с/м |
| `travel` | ход подвески, м |
| `com_offset` | центр масс от центра габаритов модели, м |
| `drive` | `"fwd"`, `"rwd"` или `"awd"` |

Все числа, кроме `com_offset`, — положительные; иначе игра не запустится, ошибка назовёт файл и поле.
