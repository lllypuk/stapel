# Платформер

`make platformer`. Игра: A/D или ←/→ — бег, Space/W — прыжок, в воздухе доступен ещё один (двойной), Enter после флага — следующий уровень.

## Редактор

F1 — войти в редактор: мир встаёт, слева панель. Повторный F1 сразу играет правку с начала уровня, даже несохранённую. Если в уровне нет игрока или он не разбирается, F1 не выпустит из редактора, а ошибка будет видна в панели.

| Действие | Как |
|---|---|
| Рисовать выбранным символом | ЛКМ, можно вести мазком |
| Стереть | ПКМ |
| Прокрутка | WASD или стрелки |
| Сохранить в файл уровня | Ctrl+S или «Сохранить» |
| Отменить мазок или изменение размера | Ctrl+Z или «Отменить» |
| Выбрать уровень, создать новый | список «Уровни», «Новый» |
| Изменить размер | ± столбец справа, ± строка сверху |

Палитра:

| Символ | Что это |
|---|---|
| `#` | земля |
| `P` | игрок; он на уровне один, новый стирает старого |
| `E` | враг |
| `o` | монета |
| `^` | шипы |
| `X` | флаг выхода |
| `=` | платформа, ездит по X; подряд идущие `=` — одна платформа |
| `H` | «блок» в панели: платформа, ездит по Y; `H` друг над другом — одна платформа |
| `!` | разворот платформ |

С несохранёнными правками сменить уровень или создать новый нельзя: сначала сохраните или отмените правки.

## Файлы

Уровни лежат в `assets/levels/levelNN.txt` и идут по имени. Файл — ASCII-карта из тех же символов, первая строка — верх уровня, `.` — пусто.

Игра сама подхватывает изменения файлов уровней, PNG и WAV, перезапускать её не нужно. Если файл изменился, пока в редакторе есть несохранённые правки, панель покажет «файл изменён на диске». Дальше два пути:

- «Загрузить с диска» — взять версию с диска;
- Ctrl+S — перезаписать файл своей версией.
