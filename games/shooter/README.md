# Шутер

`make shooter`. Карта — `assets/levels/level01.txt`, читается один раз при запуске; ошибка разбора останавливает игру с номером строки. Строки одной длины, первая — север, клетка — 2 м. Цель — дойти до выхода; смерть и победа ждут Enter, уровень начинается заново целиком.

| Действие | Ввод |
|---|---|
| Ход, шаг вбок | W/S, A/D |
| Обзор | мышь; клик захватывает курсор, Esc отпускает |
| Выстрел | ЛКМ, зажатая — очередь по скорострельности |
| Мгновенный бластер / бластер со снарядом | 1 / 2 |
| Заново после смерти или выхода | Enter |

| Символ | Что это |
|---|---|
| `#` | забор |
| `T` | дерево |
| `R` | камень |
| `.` | трава |
| `P` | игрок, ровно один; смотрит на первую соседнюю клетку травы в порядке N, E, S, W |
| `X` | выход, ровно один |
| `k` | ключ; один открывает все двери |
| `D` | дверь; касание с ключом открывает её, проходима после конца анимации; без `k` на карте — ошибка |
| `+` | аптечка; при полном здоровье не берётся |
| `a` | патроны обоим оружиям |
| `m` | враг ближнего боя: медленнее игрока, крепкий, бьёт вплотную |
| `s` | стрелок: держит дистанцию и стреляет снарядом |
| `f` | быстрый: быстрее игрока, слабый, бьёт ногой |

Бой идёт на плане: высота прицела не важна. Враг спит, пока не увидит игрока или не будет ранен. Закрытая дверь держит ход, взгляд, выстрел и снаряд; снаряды врагов пролетают сквозь врагов.
