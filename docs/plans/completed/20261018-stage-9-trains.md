# Этап 9: поезда в изометрии

## Overview
- Новая игра `games/trains` — песочница:
  - путь из деталей Kenney Train Kit по карте из файла;
  - окружение: дороги Kenney 3D Road Tiles и здания Kenney City Kit Commercial;
  - состав собирается в депо перед поездкой: локомотив и вагоны;
  - поезд управляется только «вперёд/назад»;
  - стрелки переводятся кликом и клавишей;
  - изометрическая камера с фиксированными углом и масштабом едет за поездом.
  - Задач, очков, сохранений и редактора нет.
- Движок: только ортографическая проекция `Camera3D`.
- Готово, когда:
  - сквозной тест на `level01`:
    - состав проезжает петлю при обоих положениях стрелки A;
    - сдаёт назад через стрелку;
    - возвращается в депо, не сходя с пути;
  - состав останавливается целиком на пути:
    - перед тупиком;
    - перед пошёрстной стрелкой, переведённой на другую ветку;
  - стрелка под составом не переводится ни кликом, ни клавишей;
  - кузова соседних вагонов не пересекаются на поворотах карты;
  - ортокамера: модель одинакового размера на экране на любом расстоянии, лучи курсора параллельны;
  - `make check`, `make cov`, `make mutants-diff` зелёные; офскрин-тесты — под `REQUIRE_GPU=1`.

## Solution Overview
- **Ортокамера — флагом в `Camera3D`.**
  - Поле `ortho: Option<f32>`: видимая высота кадра в мире, `None` — перспектива.
  - `enum Projection` отвергнут: `fov_y` ортокамере не нужен, а в трёх играх читается напрямую.
  - Слой оружия явно ставит `ortho: None`: иначе он унаследует ортографию сцены, и его `fov_y` молча перестанет действовать.
- **Путь — граф в игре, физики нет.**
  - Рёбра — детали, ось каждой — ломаная из таблицы с накопленной длиной.
  - Аналитические дуги не совпадают с рельсами Kenney на 5–11 см, хотя тесты формулы зелёные. Таблицу проверяет тест по мешу.
  - Стык — совпадение концов деталей по точке и коллинеарной касательной.
  - Стрелка — стык, где с одной стороны одна деталь, а с другой две: две перекрывающиеся детали из одной точки. Переход ветка → ветка невозможен по касательным.
- **Маршрут состава хранится явно.**
  - Состав — упорядоченный список рёбер под всем поездом плюс отступы головы и хвоста.
  - Список растёт у ведущего конца и укорачивается у ведомого. Задний ход ведёт хвостом и не переворачивает список.
  - В игре стрелка под составом заперта. Но `train.rs` и без запирания не перекидывает хвост на другую ветку при переводе стрелки: это его собственная гарантия, тест обходит `switch`.
- **Стрелки и тупики — по ведущему физическому концу состава** с запасом `MARGIN`: зазор и снос хорды кузова с оси на повороте.
  - Тупик останавливает состав.
  - Пошёрстная стрелка, переведённая на другую ветку, тоже останавливает: взреза нет.
- **Вагоны ставятся по пути.**
  - Тележки — точки маршрута на отступах от головы. Кузов — по хорде между тележками. Тележки повёрнуты по касательной.
  - Зазор `GAP` — минимальный, при котором кузова не пересекаются на `corner-large`.
  - Сцепка ставится по хорде между вагонами и растягивается на зазор.

## Technical Details
- **Движок** (`engine/src/camera.rs`, `mesh_pipeline.rs`):
  - `Camera3D::ortho: Option<f32>`, по умолчанию `None`;
  - `view_proj` при `Some(height)` берёт `directx::orthographic` с шириной `height·aspect` и той же глубиной: `near` → 0, `far` → 1;
  - камера слоя оружия — `Camera3D { fov_y, near, ortho: None, ..scene.camera }`.
- **Ассеты** (`games/trains/assets/`):
  - `train/`: пути `railroad-straight`, `-corner-large`, `-corner-small`, `-curve`, `train-connector`, 4–5 локомотивов (хотя бы один паровоз и один `diesel-box`) и 6–8 вагонов;
  - `road/`: 8–12 плиток (прямая, поворот, перекрёсток, газон), сконвертированных в GLB скриптом `games/trains/tools/gltf_to_glb.py`;
    - скрипт на stdlib: JSON и раскодированный `data:`-буфер — в GLB-контейнер, чанки выровнены до 4 байт;
    - скрипт вне `make check`, покрытия и мутантов;
  - `city/`: 6–8 зданий;
  - у `train/` и `city/` свои `Textures/`;
  - `CREDITS.md` — CC0 Kenney, ссылки на три набора.
- **Высоты:**
  - верх рельса — `RAIL_TOP = 0,1` над землёй: корень `y = −1` компенсируется сдвигом +1;
  - плитка дороги после масштаба 2/3 опущена так, что её трава на y = 0;
  - земля-квад — на `GROUND_DROP` ниже нуля;
  - здания стоят на y = 0 с общим масштабом `CITY_SCALE` и своим `scale` в записи.
- **Игра** (`games/trains/src`):
  - `piece.rs`:
    - `Piece { Straight, CornerLarge, CornerSmall, Curve }` плюс флаг `mirror` (`scale.x = −1`);
    - у каждой детали: имя GLB, точные конец и касательная, ось — ломаная-константа в осях детали, длина, `point_at(s) -> (Vec2, Vec2)` (точка и касательная);
    - таблица оси снимается один раз с меша: отбираются вершины с `y = max` (головки рельсов), точка оси — середина четырёх точек сечения;
    - тест сверяет константы с мешем, а не меш с самим собой.
  - `consist.rs`:
    - `Car { model, length, bogies: [f32; 2] }`;
    - длина — габарит модели по z;
    - отступы тележек — от переднего края кузова;
    - передняя тележка — `wheels-front`, задняя — `wheels-back`, а без неё — середина узлов `wheel` по z, такие колёса не поворачиваются;
    - `MAX_CARS`, `max_len(cars)` — длина самого длинного допустимого состава.
  - `track.rs`: TOML-карта.
    - Формат:
      - `[[rail]] piece, cell = [x, z], rot, mirror` — клетка 2, поворот кратен 90;
      - `[[road]] tile, cell, rot`;
      - `[[building]] model, pos, rot, scale`;
      - `depot = { rail }` — тупиковая деталь депо.
    - Путь депо — цепочка деталей от `depot.rail` до первой стрелки. «Начало депо» — хвост состава у тупика с запасом `MARGIN`, голова к стрелке.
    - Граф `Track { edges, ports, switches }`, каждое ребро — с концами `(port, сторона)`.
    - `Track::parse(text, max_len)` отдаёт ошибки с номером записи:
      - неизвестная деталь;
      - концы в одной точке с неколлинеарными касательными;
      - больше одной детали по обе стороны стыка;
      - больше двух деталей с одной стороны;
      - `depot.rail` не тупик;
      - путь депо короче `max_len + MARGIN`.
  - `train.rs`:
    - `Train { route: VecDeque<(edge, dir)>, head, tail, speed, cars: Vec<Car> }`;
    - `advance(dt, track)` двигает ведущий конец и переходит через все стыки, пересечённые за тик. Если переход невозможен — тупик или пошёрстная стрелка на другой ветке — состав встаёт с запасом `MARGIN`;
    - `cars_at(track)` — позиции тележек, кузовов и сцепок;
    - газ: педаль по ходу разгоняет, против хода тормозит, как в гонках. Разгон делится на число вагонов, предел — `MAX_SPEED`.
  - `switch.rs`:
    - стрелка «под составом», если её точка внутри маршрута; `toggle` такой стрелки запрещён;
    - ближайшая стрелка впереди ищется по графу от ведущего конца через активные ветки, не дальше `LOOKAHEAD`;
    - при нулевой скорости направление поиска — последнее направление движения, на старте — вперёд;
    - клик: `cursor_ray` пересекается с плоскостью y = 0, берётся ближайшая стрелка в радиусе `PICK`.
  - `depot.rs`:
    - egui-панель с очередью команд, как гараж в гонках: выбор локомотива, добавление и удаление вагонов, «Ехать»;
    - состав стоит на пути депо и меняется на глазах;
    - открывается, только когда поезд стоит на пути депо; пересборка ставит состав в начало депо.
  - Клавиши:
    - W/S или ↑/↓ — газ вперёд/назад;
    - E — стрелка впереди;
    - ЛКМ — стрелка под курсором;
    - Tab — депо.
  - Сцена:
    - ортокамера: изометрия `yaw = 45°`, `pitch = −35,26°`, `ortho = VIEW_HEIGHT`, едет за серединой состава с интерполяцией;
    - туман выключен, солнце — без теней;
    - у стрелки активная ветка поднята на `SWITCH_LIFT`, чтобы не мерцать с неактивной, а неактивная притемнена `tint`;
    - тележки повёрнуты `Pose::local_mut`;
    - HUD — скорость и «стрелка занята» на секунду после отказа.
  - Звука нет: пользователь его не просил.
- **Карта** `assets/maps/level01.toml`. Схема по стрелкам:

  ```
           D ──── депо (тупик, ≥ max_len + MARGIN)
   ┌───────┴───────────────┐
   │        петля          │
   │                       │
   └──A═══════════════B────┘      ═ — обгонный путь с шагом 2
       ╲  S       S'  ╱           S — curve, S' — curve с mirror
        ═══C═════════
           └── тупик T
  ```

  - **A** — петля / обгонный: проезд петли в обоих положениях.
  - **B** — схождение обгонного с петлёй. С обгонного при B «на петлю прямо» — остановка перед пошёрстной стрелкой.
  - **C** — отросток к тупику T: остановка перед тупиком.
  - **D** — путь депо: старт и возврат.
  - Задний ход — через A с обгонного на петлю.
  - Квартал дорог и зданий — внутри петли.
  - Тесты берут карту через `include_str!`.
