# Этап 3: коллизии, кинематика, триггеры, микшер и платформер

## Overview
- Движок: целочисленная физика по модели Celeste (Actors и Solids) с тайловой картой и сенсорами, пиксельный letterbox, звук — декод WAV/OGG, микшер, устройство `cpal`.
- Игра `games/platformer`: уровень из ASCII-карты шире экрана, камера за игроком, бег и прыжок, движущиеся платформы, монеты, шипы, выход, патрулирующие враги (прыжок на голову убивает). Ассеты — CC0 Kenney, музыка — CC0 OGG по кругу.
- Готово, когда: игрок не застревает и не проваливается (сценарные тесты и случайный прогон на настоящей карте зелёные); звук без треска на слух при насыщении эффектами, счётчики аудио в норме; `make check`, `make cov`, `make mutants` и CI зелёные.

## Solution Overview
- Физика — свободные функции движка над `Tilemap` и срезами тел; о `World` не знает. Тела — компоненты игры; шаг физики собирает срезы из хранилищ и пишет результат обратно.
- Позиции целые в мировых пикселях плюс дробный остаток; Actor движется по осям (X, потом Y) шагами в 1 px — туннелирования нет, застревания нет, пока старт свободен.
- Триггеры и контакт с врагами — сенсоры, проверяемые на каждом пиксельном шаге: известны ось и направление контакта, поэтому топтание определяется точно. Заметённые AABB двух движущихся тел ложно пересекаются (касаются в разное время) — не используются. Сенсор ловит только вход **движущегося** тела; вход врага в стоящего игрока ловит проверка пересечений в конце тика.
- Откладываются (правка `docs/design.md`): круг, общая сетка для динамических тел (их десятки, перебор), слои и маски, события enter/exit, `Stop` и кража голосов. `Transform` в движок не переезжает: тела платформера (целые AABB) и Asteroids (f32 с углом) разные.
- Пиксельный letterbox: целый масштаб, целые отступы, камера и края всех спрайтов на целых мировых пикселях — швов атласа без экструзии нет.
- Звук: игра шлёт команды через `rtrb`, колбэк `cpal` микширует фиксированный пул голосов без аллокаций; `Stream` живёт в `Running` и дропается раньше `Assets`.

## Technical Details

### Физика (`engine/src/physics/`)
- `Aabb { min: IVec2, size: IVec2 }` — полуоткрытый `[min, min + size)`, размеры положительные; `overlaps` — строгое пересечение, касание гранями — не пересечение.
- `Tilemap { tile: i32, width: i32, height: i32, solid: Vec<bool> }`, строка 0 — нижняя (Y вверх). Ячейки AABB — `div_euclid` от `min` и от `max − 1`. Вне карты сначала X: слева и справа — твёрдое (и в углах), иначе сверху и снизу — пусто (снизу яма).
- Остаток: `remainder += delta; step = remainder.round(); remainder -= step` — как в Celeste.
- `Actor { aabb, remainder: Vec2 }`: `move_actor(map, solids: &[Aabb], actor, delta, sensors: &[Aabb], contacts: &mut Vec<Contact>) -> Hits { x, y }` — остаток плюс приватная `move_exact(…, IVec2, …)` без остатка; целая часть проходится шагами по 1 px по X, затем по Y; шаг в твёрдое (тайл или `Solid`) — стоп по оси, остаток оси обнуляется. После каждого шага сенсоры, с которыми началось пересечение, пишутся в `contacts` как `Contact { sensor, axis, dir }`; сенсор, с которым тело пересекалось до шага, не повторяется.
- `grounded(map, solids, aabb)` — сдвиг на 1 px вниз пересекает твёрдое; отдельно от `overlaps`.
- `Solid { aabb, remainder }`: `move_solid(map, solids: &mut [Solid], i, delta, actors: &mut [Actor], sensors: &[Aabb], contacts: &mut Vec<(usize, Contact)>, squished: &mut Vec<usize>)` — сенсоры общие, индекс в `contacts`/`squished` — Actor; чужие контакты игра отбрасывает. Solid проходит сквозь тайлы и другие Solid сразу на целую часть по каждой оси; разворот на `!` и о твёрдое делает игра. Riding (стоит сверху) собирается **до** движения по обеим осям; пока Solid двигается, он исключён из препятствий своих пассажиров и толкаемых. Пересечённого Actor Solid толкает `move_exact` на глубину пересечения по оси (push важнее carry); неудачный push — `squished`. Пассажира везёт `move_exact` на точный сдвиг Solid, остаток пассажира не трогается; через остаток сдвиг округлился бы в лишний пиксель. Заблокированный carry — не смерть. Actor не опора другому Actor.
- Порядок тика игры: ввод → логика → платформы (`move_solid`) → враги → игрок → контакты (включая пересечение игрока с живыми врагами в конце тика) → `cmds.apply`. `prev` сохраняется один раз до всех перемещений тика; респаун — в том же тике, что смерть, и сбрасывает `prev`, `remainder`, скорость и `prev` камеры. Раздавленный враг — `despawn`: стартуя внутри Solid, он застрял бы.

### Вьюпорт (`engine/src/camera.rs`, `engine/src/renderer.rs`, `engine/src/lib.rs`)
- `letterbox_pixel(surface, world) -> Viewport`: масштаб `k = floor(min(W/w, H/h))`, отступы — целочисленное деление остатка пополам (поля различаются максимум на 1 px). При `k < 1` — дробный `letterbox`. Размер поверхности физический; `scale_factor` повторно не умножается. Пример: 1366×768 → `k = 4`, вьюпорт 1280×720, отступ (43, 24).
- `viewport(surface, &Camera2D, pixel_perfect) -> Viewport` — чистый выбор между `letterbox` и `letterbox_pixel`; `Renderer::draw` только вызывает его (`renderer.rs` вне покрытия, `Renderer::` вне мутантов).
- `Config { pixel_perfect: bool }` → `Renderer::new(window, vsync, pixel_perfect)`; Pong, Asteroids, clear-color — `false`.
- Платформер рисует камеру и все спрайты так, что края спрайтов на целых мировых пикселях: позиция `round(lerp(prev, cur, alpha))` с одним `alpha` для всех, центр спрайта нечётного размера — на `.5`. Округлённая камера без округлённых спрайтов даёт дрожание спрайтов относительно тайлов.
- Отражение спрайта — перестановка `uv.min.x` и `uv.max.x`.

### Звук (`engine/src/audio/`)
- `Assets::load_sound(path) -> Handle<Sound>`: `.wav` — `hound`, только PCM 16 бит (так конвертируются ассеты); `.ogg` — `lewton`. Моно → стерео; другое число каналов или формат — `warn` и пустой звук. Линейный ресемплинг в частоту `Assets::sample_rate` (по умолчанию 48 000); частота файла — из заголовка. Нет файла или битый → `warn` и пустой звук.
- `Assets::set_sample_rate` — `pub(crate)`, только до первого `load_sound` (`debug_assert!`), иначе кэш молча хранит звук чужой частоты.
- `Sound { frames: Arc<[f32]> }` — стерео-интерлив, поля `pub(crate)`, публичного конструктора нет; доступ — `Assets::sound(Handle<Sound>) -> &Sound`. `Assets` держит `Arc` вечно (выгрузки нет), поэтому последняя ссылка не освобождается в колбэке.
- `Mixer` — чистая структура: 32 голоса эффектов + слот музыки; голос = `{ frames, pos, volume, looping }`. `render(&mut self, out: &mut [f32])` — стерео, сумма × мастер 0,5, клип в `[-1, 1]`. Огибающая в аудиофреймах, одинаковая для L/R: `min(fade_in, fade_out)` по 64 фрейма — у звука короче 128 фреймов они не складываются. Музыка: fade-in только на первом старте, на стыке цикла огибающей нет. Не больше 64 команд за вызов. Все голоса заняты — новый эффект отбрасывается со счётчиком (без кражи — без щелчка кражи).
- `Command::Play { frames, volume }` — эффект, `Command::Music { frames, volume }` — слот музыки по кругу; новая `Music` поверх играющей обрывает её со щелчком — зовётся только из `init`. Пустой звук не запускается.
- `Audio` в `Context`: `play(&Sound, volume)`, `play_music(&Sound, volume)` — `rtrb::Producer<Command>`; очередь полна — отброс со счётчиком. `Context::default` — немой `Audio`.
- `device.rs`: `cpal` default output; просим 48 000 стерео f32, иначе формат устройства по умолчанию; формат не `f32`/`i16` — `warn` и немой `Audio`; `stream.play()`. Заполнение буфера устройства — чистая `fill(mixer, scratch, out, channels)` в `audio/mod.rs`, под тестами: микс кусками в заранее выделенный `scratch` (запрос длиннее буфера — несколько кусков) и конверсия стерео f32 в формат и каналы устройства (`f32`, `i16`; моно — среднее; больше двух — L, R, нули). В `device.rs` — только `build_output_stream`, вызов `fill` и замер времени. Нет устройства — `warn` и немой `Audio`. Лог из error-колбэка аллоцирует на аудиопотоке — допустимо только на пути ошибки.
- Открытие устройства — в `resumed` до `Game::init`; частота — в `Assets`. `Stream` — поле `Running`, объявленное **раньше** `ctx`: поля дропаются по порядку объявления, `Stream::drop` останавливает колбэк до освобождения `Assets`.
- Счётчики — атомики: макс. время колбэка, бюджет (длина буфера / частота), отброшенные команды; `App` пишет их раз в секунду: `audio cb 0.4/10.7ms dropped 0`. Диагностика, не доказательство: критерий — прослушивание при насыщении.
- `[profile.dev.package.{lewton,ogg}] opt-level = 3`: полный декод музыки в debug иначе занимает секунды.

### Платформер (`games/platformer`, tick 60, мир 320×180)
- Ассеты Kenney Pixel Platformer: `tilemap_packed.png` (тайлы 18×18), `tilemap-characters_packed.png` (24×24); UV ячейки — `cell × 18 / размер атласа`. Звуки: `jump`, `coin`, `stomp`, `hurt`, `win` — из OGG Kenney через `ffmpeg -i x.ogg -c:a pcm_s16le x.wav`; `music.ogg` — CC0 loop-ready, стык проверяется прослушиванием. `CREDITS.md` с источниками, лицензиями и командой конвертации.
- Карта `assets/level1.txt`, первая строка — верх: `#` земля, `^` шипы (сенсор 18×8 у низа клетки), `o` монета, `E` враг, `P` старт, `X` выход, `=` горизонтальная платформа (подряд по горизонтали — одна), `H` вертикальная (подряд по вертикали — одна), `!` стоп для платформ (для Actor не твёрдый), пробел и `.` — пусто. Ширина ≥ 4 экранов; строки разной длины и неизвестные символы — ошибка парсера с номером строки.
- Игрок: хитбокс 12×16; бег до 1,5 px/тик с разгоном; гравитация 0,25 px/тик²; прыжок 4,5 px/тик; отпускание при подъёме — `vel.y × 0,5`; падение до 5 px/тик; койот и буфер прыжка — по 6 тиков. Числа стартовые, подбираются игрой.
- Враги: 0,5 px/тик, разворот у стены и перед краем (опора впереди — тайл или платформа).
- Камера: мёртвая зона по X, зажатие в границы уровня.
- Контакты: шип, враг не сверху, пересечение с живым врагом в конце тика без топтания, раздавлен, ниже уровня — смерть; контакт с врагом по оси Y с `dir = −1` — топтание (враг в `despawn`, отскок `vel.y = 3`). Приоритет в тике: смерть > выход > монеты; `is_pending` против двойных последствий.
- Тик копит события `Sfx` (`Jump`, `Coin`, `Stomp`, `Hurt`, `Win`); тестируется чистое `fn sound(&self, Sfx) -> Handle<Sound>`, цикл `ctx.audio.play` по событиям — прямо в `update` (вызов через немой `Audio` не наблюдается, мутант функции-обёртки выжил бы).
- Смерть — респаун на `P`, счётчик смертей; собранные монеты и убитые враги не возвращаются. Выход — `LEVEL CLEAR`, время, монеты `n/N`, смерти; Enter — уровень заново.
- HUD — JetBrains Mono из `assets/fonts/`.
- ГПСЧ для случайного прогона — свой xorshift в тесте, без `rand`.
