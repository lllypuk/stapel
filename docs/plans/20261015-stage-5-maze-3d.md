# Этап 5: первый 3D — модели glTF, скелетная анимация, свет и лабиринт

## Overview
- Движок: `Camera3D` и буфер глубины, конвейер мешей (статичный instancing и скиннинг), загрузка glTF (узлы, меши, скины, анимации), поза по анимации, точечный свет, туман, обзор мышью с захватом курсора; 2D и egui поверх 3D.
- Игра `games/maze`: лабиринт от первого лица из ASCII-карты, модели Kenney Mini Dungeon (CC0): стены, пол, ворота с анимацией `open`, ключ, монеты, орки-патрули с анимацией `walk`, факелы у баннеров, выход; миникарта и HUD спрайтами, отладочная панель egui по F1.
- Готово, когда: лабиринт проходится с ключом через ворота до выхода, орк идёт анимацией и рестартит при касании, свет факелов и туман видны; `make check`, `make cov`, `make mutants` и CI зелёные.

## Solution Overview
- **Проходы:** 3D (`Clear` цветом тумана и глубины, на всю поверхность, aspect поверхности, `cull_mode: None` — материалы Kenney `doubleSided`) → спрайты (`Load`, если 3D был; HUD — `Camera2D` с letterbox) → egui.
- **Сцена кадра** — `gfx.scene: Option<Scene { camera, ambient, fog, lights, meshes, models }>`; `step_frame` ставит `None` перед `draw`, как чистит спрайты. `None` — 2D-игры не меняются.
- **Модель** (`Handle<Model>`): CPU-часть в `Assets` — узлы (родитель, локальный TRS, меш, скин), скины (суставы в порядке `skin.joints`, inverse bind), анимации `LINEAR` (каналы узел/путь/времена/значения); `STEP` и `CUBICSPLINE` — ошибка загрузки. Индексы расширяются до u32. Вершины — `PendingMesh` рядом с `PendingTexture`. Ошибка — пустая модель и `warn`. Модели не перезагружаются горячо.
- **Поза** — чистый CPU: сэмпл каналов (T/S — lerp, R — slerp по короткой дуге, вне диапазона — крайний ключ), время по модулю длины или зажато, глобальные матрицы узлов, палитра скина `G_joint × IBM`.
- **Трансформации** (codex): жёсткий меш — `M_entity × G_mesh × p`, `G_mesh` из позы, если она есть (ворота), иначе из покоя; меш со скином — `M_entity × Σ(wᵢ × G_jointᵢ × IBMᵢ) × p`, `G_mesh` не применяется. Палитра — на пару «экземпляр–скин».
- **Нормали:** жёсткий меш — обратная транспонированная `M_entity × G_mesh` на CPU на инстанс; скин — та же смесь матриц без обратной транспонированной: точно при поворотах и равномерном масштабе суставов, у Kenney масштаба нет.
- **Конвейер мешей:** один шейдер, два входа. Статичные меши — instancing, батчи по `(mesh, texture)`. Скин — вызов на инстанс, палитра в uniform-буфере с динамическим смещением, шаг `MAX_JOINTS × 64 = 4096` Б, кратность лимиту устройства проверяется при создании. Storage-буфер в вершинном шейдере на GL может отсутствовать. Таблица текстур GPU — общая.
- **Свет:** ambient + до `MAX_LIGHTS = 16` `PointLight { pos, color, range }`, Ламберт по фрагменту, затухание `max(1 - d/range, 0)²`, туман `clamp((d - start)/(end - start), 0, 1)` к цвету тумана. Больше 16 — движок берёт первые 16 и пишет `warn` один раз; игра не даёт карте больше 16 факелов.
- **Обзор мышью:** `Input::mouse_delta` — сырой `DeviceEvent::MouseMotion`, копится, сбрасывается `end_tick`. `update` прибавляет сдвиг к yaw/pitch; `draw` рисует камеру с непотреблённым сдвигом и состояния не меняет. Движение и столкновения — по углу тика.
- **Захват курсора:** игра ставит `ctx.cursor_grab`; app пробует `Locked`, затем `Confined`, прячет курсор после успеха и пишет итог в `ctx.grabbed`; обе попытки неуспешны — `cursor_grab = false` и `warn` один раз. Сдвиг принимается только при фокусе и `grabbed`. Потеря фокуса снимает захват, `cursor_grab`, сдвиг. `ctx.focused` стартует с `window.has_focus()`. Игра берёт захват только по `mouse_just_pressed` при `ctx.focused`.
- **Мипы не нужны:** `colormap` — плавные градиенты без детализации. Фильтр — общий `Nearest`; вид — запуск.
- **Игра:** позиции игрока и орков — `prev`/`cur` с интерполяцией в `draw`, рестарт ставит `prev = cur`. Глаз — 0,7 м. Столкновения — круг игрока против клеток стен и закрытых ворот по осям со скольжением, в игре. Враги — патруль по прямой с разворотом у стены. Касание — рестарт уровня.

## Technical Details

### Движок
- `lib.rs`: реэкспорт `Vec3`, `Mat4`, `Quat`.
- `camera.rs`: `Camera3D { pos, yaw, pitch, fov_y, near, far }`, `forward`, `view_proj(aspect)`; pitch зажат в `±(π/2 - ε)`.
- `gpu_textures.rs`: таблица bind group текстур, `upload` из `Assets` (push/замена), общий layout; `gpu_test` — офскрин-хелперы и создание глубины (`depth_texture(device, size)` общее с `Renderer`).
- `mesh.rs`: `Vertex { pos, normal, uv, joints: [u16; 4], weights: [f32; 4] }`, `PendingMesh`, `Handle<Mesh>`.
- `scene.rs`: `Scene`, `PointLight`, `Fog`, `MeshDraw { mesh, texture, transform }`, `ModelDraw { model, transform, pose: Option<Pose> }`; раскрытие в `MeshInstance` и `SkinnedDraw` — чистые функции.
- `model.rs`: `Model`, `Node`, `Skin`, `Animation`, `Channel`, разбор GLB; `Pose { globals, palettes }`, `Model::pose(anim, t, looped, &mut Pose)`.
- `mesh_pipeline.rs` + `mesh.wgsl`: `vs_static`, `vs_skinned`, `fs`; uniform сцены (view_proj, ambient, fog, lights — `vec4`-выравнивание полей), буфер палитр.
- `input.rs`: `on_mouse_motion(Vec2)`, `mouse_delta()`; `frame.rs`: `Context { focused, cursor_grab, grabbed, .. }`.
- `ui.rs`: `set_font(&egui::Context, path)` — перенос из платформера, нужен двум играм.

### Игра `games/maze`
- Карта: `#` стена, `.` пол, `P` старт (взгляд — на первую соседнюю клетку пола по порядку N, E, S, W), `E` орк, `o` монета, `k` ключ, `D` ворота, `X` выход (`stairs`), `T` факел (баннер на ближайшей стене). Ошибки: неровная строка, неизвестный символ, нет/два `P`, факелов больше 16, `T` без соседней стены.
- Клетка — 1 м, модели в метрах, Y вверх.
- Игрок: радиус 0,25 м, глаз 0,7 м, скорость по WASD относительно yaw; закрытые ворота твёрдые; открытие — `open`, проходимы после конца анимации (дверь выше стен на 0,4 м — видно сверху, принимаем).
- Монеты крутятся кодом; ключ и монета берутся касанием; победа на `X`, Enter — заново.
- Орк: патруль по оси коридора, разворот у стены и закрытых ворот, `walk` по пройденному пути, касание — рестарт (монеты и ключи сброшены).
- Факел: баннер + `PointLight` с мерцанием от тиков.
- Миникарта: клетки, открытые в радиусе вокруг пройденного пути, игрок стрелкой; спрайты поверх 3D; HUD — `draw_text` шрифтом `assets/fonts/JetBrainsMono-Regular.ttf`.
- F1: панель egui — FPS, ambient и туман ползунками через команды, применённые в `update`; на время панели захват снят.
