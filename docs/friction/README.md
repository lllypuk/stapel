# Журнал трения

Сюда копируется `FRICTION.md` игры, которую холодная сессия агента написала на движке, как `<дата>-<игра>.md`. Рядом — критерии, по которым принималась игра, и результат сверки.

Запись:

```
## <заголовок>
- Doing / Expected / Happened / Cost / Workaround / Wanted
```

Формат полей — в `docs/agents/AGENTS.md`, его же получает сессия.

Каждая запись разбирается в один из четырёх исходов, записанных под ней строкой `Исход:`:

- правка движка — коммит или задача плана;
- правка доков — `README.md`, `docs/agents/AGENTS.md` или `docs/design.md`;
- пункт следующего этапа — со ссылкой на строку этапа;
- не чиним — с причиной.

Запись без исхода — журнал не разобран.
